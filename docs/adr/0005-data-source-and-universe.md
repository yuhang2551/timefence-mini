# ADR 0005：数据源用 akshare（东方财富），股票池用每日流动性前 500

- 状态：已采纳
- 日期：2026-10-13

## 背景

免费的 A 股数据源各有问题：tushare 很多接口要积分，baostock 走 TCP 长连接（很多云环境不通），akshare 的东方财富接口走 HTTPS、覆盖全、不用注册。另外 akshare 拿不到历史上的指数成分股，用"今天的沪深 300"回测会有幸存者偏差。

## 决定

1. **行情**：akshare 的 `stock_zh_a_hist`，同一只股票分别取不复权和后复权两份，用"后复权收盘 ÷ 不复权收盘"得到复权因子。两份价格都四舍五入到分，比值会有 0.2% 左右的抖动，所以把它清洗成阶梯函数（只有持续的变化才算真正的除权）。成交量从"手"换算成"股"。
2. **股票列表**：当前上市的（`stock_zh_a_spot_em`）加上已退市的（`stock_zh_a_stop_em`），这样历史里包含后来退市的股票。
3. **股票池**：每天按过去 20 天平均成交额取前 500 只，要求当天有成交、上市满 365 天（用第一根日线的日期近似上市日），剔除北交所。只用当天收盘前已知的信息。
4. **每只股票单独缓存成一个 Parquet 文件**，下载中断后可以接着下。
5. 数据从 2016 年开始，给 2018 年开始的训练集留出因子需要的历史。

## 代价

- 东方财富的接口不是官方 API，字段或限流可能变化；下载代码带重试，失败的股票会列出来。
- 用第一根日线作上市日，对 2016 年以前上市的股票只是个下限；因为训练集从 2018 年开始，不影响结果。
- 流动性股票池和指数成分股不完全一样，但它没有幸存者偏差，而且更接近实际能交易的范围。
