# ADR 0004：回测规则与简化

- 状态：已采纳
- 日期：2026-10-13

## 决定：模拟这些 A 股规则

| 规则 | 实现 |
|---|---|
| 收盘决策、次日开盘成交 | 回测循环在 t 日收盘后调策略，订单在 t+1 开盘撮合 |
| T+1 | 当天买入的股票当天不能卖（`Broker` 记录当日买入量） |
| 涨跌停 | 开盘价触及涨停不能买，触及跌停不能卖；主板 10%，创业板 2020-08-24 起 20%（之前 10%），科创板 20%，北交所 30%（股票池已剔除） |
| 除权日的涨跌停基准 | 昨收 × 昨日复权因子 ÷ 今日复权因子，和交易所的除权参考价一致 |
| 停牌 | 没有成交的股票不能买卖，估值用最近收盘价 |
| 整手 | 100 股一手；清仓时允许卖出零股 |
| 分红送转 | 除权日按复权因子比例调整持股数（相当于红利再投资） |
| 退市 | 退市后按最后收盘价卖出，报告里列出次数 |
| 成本 | 佣金万 2.5、最低 5 元；过户费十万分之一；卖出印花税 2023-08-28 前 0.1%、之后 0.05%；滑点 5 个基点 |

## 简化（都写在 README 里）

- ST 股票实际涨跌停 5%，没有历史 ST 标记，按板块处理。
- 科创板实际 200 股起买、之后按 1 股递增，这里统一 100 股一手。
- 不模拟现金分红到账时间和红利税。
- 不模拟冲击成本，适合几百万到几千万的规模。

## 为什么用"昨日股票池等权"作基准

和策略选股用的是同一个股票池，比较的是"选股能力"，而不是"选了什么池子"。基准不计成本，所以超额收益是保守的。
