# ADR 0006：模型调用走缓存和预算，提示词要求 JSON

- 状态：已采纳
- 日期：2026-10-13

## 决定

1. **只用兼容 OpenAI 协议的接口**（默认 DeepSeek），模型名、地址、密钥环境变量都可以从命令行换。没有用 LangChain 的模型封装，少一层依赖，行为更透明。
2. **磁盘缓存**：请求内容（模型、消息、温度）的哈希作为键，回复存成 JSON。重跑同一个实验时直接读缓存：不花钱，结果完全一样。
3. **预算**：每次运行限制调用次数和 token 数，超了就停在当前轮，已经做完的工作都在研究记忆里，不会丢。
4. **要求 JSON 输出**（`response_format=json_object`），解析失败时当作"没有提案"处理，走重试，不会让流程崩掉。
5. **完整记录**：每次调用的输入输出写进 `transcript.jsonl`，方便事后看模型是怎么想的。
6. **密钥只从环境变量读**，代码、配置、日志里都不出现。
7. **离线替身**（`--offline`）：不调模型，按模板生成表达式，让整个流程不联网也能跑；报告里会标明"不是大模型"。测试里用 `ScriptedLLM` 精确控制模型的回复。

## 为什么不用函数调用（tool calling）

这个流程里模型只需要"给出几个表达式和理由"，工具（打分、验收）由流程本身调用，不需要模型决定什么时候调。用 JSON 输出更简单，换模型也更容易。
